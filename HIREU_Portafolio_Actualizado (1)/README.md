# Portafolio HIRE-U actualizado

## Contenido
- `index.html`: portafolio del Proyecto Integrador.
- `documentos/`: siete PDF correspondientes a acta, plan de gestión, EDT, RACI, PERT, manual y presupuesto.

## Publicar en GitHub Pages
1. Descarga y descomprime este paquete.
2. Copia `index.html` y la carpeta `documentos/` a la raíz del repositorio `Portafolio-hire-u-2.0`.
3. Conserva la imagen `Logo HIRE-U 2.0.png` en la raíz del repositorio. El HTML utiliza esa ruta para el logo y favicon.
4. Conserva la carpeta `img/` existente; no es necesario borrarla.
5. Haz commit y push a la rama `main`.
6. En GitHub, abre Settings → Pages y confirma que se publique desde la rama `main` y la raíz (`/root`).
7. Comprueba que la página y cada PDF abran correctamente.

## Importante
Los tiempos, costos y distribución RACI son propuestas académicas y deben validarse con el equipo. El manual describe funciones condicionales; no debe interpretarse como confirmación de que todos los módulos ya estén implementados.
